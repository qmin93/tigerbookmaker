# 가치 사다리 v0 (Day 1)

> 책 Secret 3 (가치 사다리) + Secret 27 (한 번에 하나씩) 기반. 4층.
> v3 실제 코드 + 가격 구조 (`app/pricing/page.tsx`, `lib/tiers.ts`) 반영.

## 현재 v3 실제 BM 요약 (참고)

- **모델**: 충전식 (선결제 → 권당 차감), 정기결제 X, 카드 등록 X
- **권당 가격**: 베이직 ₩500 / 프로 ₩1,500 / 프리미엄 ₩7,000 (모델 비용 + 마진)
- **시나리오 가격 안내**: 권당 ₩4,000–₩21,300 (티어 + 길이별)
- **베타 무료 크레딧**: 회원가입 시 ₩5,000 자동 지급
- **환불**: 7일 100%
- **타겟 명시**: "직장인 부수익러" → 크몽 ₩40,000 판매 시나리오 가정

→ 즉 v3는 이미 **층 2 (저가 진입) 위주의 단일 퍼널**이 깔려 있음. 층 1 (리드 마그넷)과 층 3+ (중고가) 는 약하거나 없음.

## 층 1: 무료 (리드 마그넷) — **현재 부족**

- **상품 후보 A**: "퇴근 후 30분, 첫 PDF 자료 자동 생성" 미니 이북 1편 (10페이지, 베이직 모델, 워터마크) — 이메일만 받음
- **상품 후보 B**: "AI 이북 키워드 SEO 체크리스트" PDF — 책 없이 가이드만
- **상품 후보 C**: "크몽 PDF 베스트셀러 분석 리포트" PDF — 시장 정보 미끼
- **목적**: 카드 정보 없이 진입 장벽 0, **이메일 리스트 확보** (현재 가장 약한 자산)
- **v3에 있나**: ❌ 거의 없음. `app/examples`가 비슷하지만 "샘플 책 열람"이지 "내 손에 PDF 받기"가 아님
- **퍼널 유형**: 리드 스퀴즈 (Secret 8) 또는 리버스 리드 스퀴즈
- **연결 가설**: 무료 미끼 다운로드 → 5일 시퀀스 이메일 (Secret 7) → 층 2 결제

## 층 2: 저가 진입 (₩4,000–₩21,300 권당) — **v3 메인**

- **상품 (현재)**: 권당 결제 (베이직/프로/프리미엄 티어)
- **상품 후보 D (책 퍼널 변형, Secret 11)**: "첫 권 무료 (배송비/처리비 ₩2k) + OTO로 두 번째 권 ₩4k"
- **목적**: 카드 정보 받기, 신뢰 구축, 실제 결과물(완성된 책) 제공
- **v3에 있나**: ✅ 완성 — 충전식 + 권당 차감 + 7일 환불
- **퍼널 유형**: 책 퍼널 (Secret 11) 또는 장바구니 (Secret 12)
- **개선 여지**:
  - 첫 책 ₩0 + 배송비 모델 도입 → 책 퍼널 전환율 8배 효과 (Secret 11)
  - 결제 직후 OTO (Secret 21): "+₩X에 표지 5종 베리에이션" / "+₩X에 워크북 추가"
  - 감사 페이지 = 오퍼월 (Secret 12)

## 층 3: 중가 (₩39,000–₩299,000) — **부분 존재**

- **상품 후보 E**: 무제한 월구독 ₩39,000/월 (인기 티어 무제한 생성)
- **상품 후보 F**: 14일 챌린지 "30분 이북 14권 챌린지" ₩99,000 (Secret 13)
- **상품 후보 G**: 표지·내지·SEO 풀패키지 + 크몽 등록 가이드 ₩149,000
- **상품 후보 H**: 시리즈 부트캠프 4주 ₩299,000 (그룹 코칭 + 무제한 생성)
- **목적**: 핵심 매출원 (월 100만원 목표 → 30–50명 결제 = 도달)
- **v3에 있나**: 부분
  - ✅ 챌린지 코드 있음 (`app/challenges`)
  - ✅ 시리즈 코드 있음 (`app/series`)
  - ❌ 월구독 BM 없음 (충전식만)
  - ❌ 패키지 상품 없음
- **퍼널 유형**: VSL (Secret 14) 또는 웨비나 (Secret 15) — 챌린지 자체가 가치 사다리이자 퍼널

## 층 4: 고가 (₩2,000,000+) — **없음**

- **상품 후보 I**: 1:1 자비출판 컨설팅 (POD 인쇄까지) ₩2,000,000
- **상품 후보 J**: 브랜드북 제작 대행 (B2B, 회사 매뉴얼 자동화) ₩5,000,000
- **상품 후보 K**: 작가 코호트 6주 프로그램 (10명 한정) ₩3,000,000
- **목적**: 가치 사다리 최상단, 고LTV, 1인 코치/B2B 대상
- **v3에 있나**: ❌
- **퍼널 유형**: 신청서 퍼널 (Secret 17) — 직접 통화·대면 필요
- **우선순위**: Month 6+ 이후. 1번 퍼널이 안정화되기 전까지는 미접근.


## 1번 퍼널 선택 가설 (Day 6에 확정)

Day 1 시점 직관:

### 후보 A: 층 1 → 층 2 리드 스퀴즈 + 책 퍼널 ⭐ 1순위

- 미끼: "퇴근 후 30분, 첫 PDF 자료 자동 생성" 미니 이북
- 결제: 베타 무료 크레딧 ₩5,000 자동 적용 → 첫 책 사실상 무료 체험
- v3 자산 100% 재사용
- 진입장벽 최저, 데이터 빠르게 모임
- **적합**: ICP-1 (크몽 셀러)에 가장 잘 맞음

### 후보 B: 층 3 챌린지 "14일 14권" — 2순위

- 챌린지 코드(`app/challenges`)와 v3 시리즈 기능 활용
- ₩99k 단일 가격 → ACV 높음
- 챌린지 자체가 후크-스토리-제안 일체
- **리스크**: 챌린지 모집에 시간·노력 큼, 1번 퍼널로는 무겁다

### 후보 C: 층 2 무료 책 + 배송비 모델 — 3순위

- Secret 11 책 퍼널의 정공법
- 권당 비용 추정 ₩2,500 → 배송비/처리비 ₩2,000 받으면 손익분기
- 즉시 카드정보 확보 + 8배 전환율 효과 (Secret 11)
- **리스크**: 디지털 상품에 "배송비" 명목이 한국 시장에 어색함. 변형 필요 ("처리비" / "환불보증금")

→ Day 6에 인터뷰·해킹 데이터 보고 1개 확정.
