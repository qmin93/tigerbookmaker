# 후크-스토리-제안 v1 (Day 5 가설)

> 책 Secret 2 기반. 만드는 순서는 제안 → 스토리 → 후크 역순.
> **현재 v1은 인터뷰 데이터 없이 가설 기반**. Day 5 인터뷰 5건 마친 후 v2로 보정.

## 가정 ICP — Day 1 ICP-1 크몽 셀러 (박지수, 32세 여성)

> ICP-1 선정 이유: 직접 경쟁사 분석 결과 (글로벌 5개 + 한국 1개) 모두 KDP 부수익 작가를 노리는데, **한국에서는 KDP보다 크몽이 훨씬 큰 시장**. tigerbookmaker만 한국 크몽 셀러를 직접 타겟팅 가능. v3 코드도 이미 "크몽 ₩40k 판매 시나리오" 명시.

## 1. 제안 (Offer) — 먼저 설계

### 메인 상품 (1번 퍼널 = 리드 스퀴즈)
- **베타 무료 시작 + 미니 이북 + 시퀀스 이메일**
- 카드 정보 받지 않음
- 가입 즉시 5개 가치 동시 제공

### 가치 스택 (Secret 20 — 합산해서 총 가치 수치화)

| 포함 | 정가 가치 |
|---|---|
| 미니 이북 1편 (10페이지 PDF, 본인 주제) — 사전예약자 한정 | ₩9,900 |
| 크몽 베스트셀러 키워드 체크리스트 PDF | ₩4,900 |
| 5일 "30분 이북 만들기" 시퀀스 이메일 강좌 | ₩19,900 |
| 베타 ₩5,000 크레딧 자동 (라이트 1권 무료) | ₩5,000 |
| 표지 30종 갤러리 평생 접근 | ₩9,900 |
| **합계 정가** | **₩49,600** |

### 가격 앵커 + 실제 가격
- **정가 (총 가치)**: ₩49,600
- **오늘 가격**: ₩0 (베타 한정)

### 보장
- **카드 정보 받지 않음** = 위험 0
- 이메일은 베타 안내·자료 발송에만 사용. 언제든 수신거부.
- 7일 100% 환불 (베타 종료 후 자동 결제 도입 시)

### 긴급성 / 희소성
- "베타 종료 시 정상가 ₩X로 전환. 사전예약자만 평생 베타 가격 유지."
- 사전예약 신청자 수 라이브 카운터 노출

## 2. 스토리 (Story) — 두 번째 설계

### 스타 (주인공)
**박지수**, 32세 여성. 회사 마케터 4년차. 본업 외 시간에 크몽에서 직무 PDF 자료 판매 시작 6개월. 현재 매출 월 ₩20만원.

> "저는 박지수예요. 작년 가을에 크몽 사이드잡 시작했어요. 처음엔 ChatGPT로 자료 만들어서 올리면 한 달에 ₩10만씩은 나오겠지 했는데… 한 권 만드는 데 2주가 걸리고, 표지는 Canva로 매번 새로 디자인하고, 키워드 SEO는 아직도 모르겠고."

### 스토리 (변화의 여정, 4–6단락 — 책 Secret 20 12단계 압축)

#### 1. 시작 상황 (페인포인트)
> "퇴근하고 노트북 켜는 게 매일 약속이지만, 실제로는 일주일에 2–3번도 어려워요. 챕터 구조 잡으려고 ChatGPT 켜면 30분이 1시간이 되고, 표지 만들려고 Canva 켜면 또 2시간."

#### 2. 시도했지만 실패한 것들
> "프롬프트 묶음 ₩9,900에 사봤어요. 좋긴 한데 결국 제가 복붙해서 정리해야 하니까 시간은 안 줄더라고요. 외주 견적도 받아봤어요 — ₩300,000. 한 달 매출보다 비싸요."

#### 3. 잘못된 믿음 (Secret 22 — 외부 도구 믿음)
> "AI는 결국 잡 글이고, 사람이 다듬어야 한다고 생각했어요. 그게 맞는 줄 알았어요."

#### 4. 깨달음
> "근데 30분 안에 12챕터 + 표지 + 본문이 다 나오는 걸 보고 생각이 바뀌었어요. AI 글이 부족한 게 아니라, **내가 다듬을 시간이 부족했던 거**예요. AI가 90% 만들어주고, 제가 10%만 손보면 일주일에 2권은 가능해요."

#### 5. 결과 (외부 + 내부)
> "지금은 매주 1–2권씩 라인업 늘리고 있어요. 매출은 월 ₩50만 넘었고, 더 중요한 건 **'주말에 일하지 않아도 매출이 들어온다'**는 감각이에요. 본업 의존도가 줄었어요."

### 솔루션 (tigerbookmaker가 어떻게 가능하게 하는지, 3개 핵심)

1. **30분 워크플로우** — 주제 1줄 + 본인 자료 1개 → 12챕터 자동 + 표지 자동 + 마케팅 카피
2. **권당 결제** — 안 만든 달은 ₩0. 만든 만큼만 ₩4,000부터.
3. **본인 권리 100%** — 만든 책은 본인 것. 크몽·KDP·블로그 자유롭게 판매.

## 3. 후크 (Hook) — 마지막 설계

### 방문자 온도별 헤드라인 3종 (Secret 18)

#### 🥶 차가운 (모르는 사람, Threads/Meta 광고용)
> **"퇴근 후 30분, 첫 PDF 자료가 나옵니다."**
> 서브: "주제 한 줄 + 자료 1개 → AI가 12챕터 + 표지 자동. 사전예약자에게 미니 이북 + 키워드 체크리스트 무료."

#### 🌤 따뜻한 (이북·크몽은 알지만 tigerbookmaker 모름)
> **"₩300,000 외주 vs 30분에 1권 — 직장인 부수익러의 새로운 답."**
> 서브: "권당 ₩4,000부터. ₩5,000 크레딧 자동 = 라이트 1권 무료."

#### 🔥 뜨거운 (tigerbookmaker 알고 결제 직전)
> **"베타 종료 D-7 — 사전예약자 평생 베타 가격 유지."**
> 서브: "오늘 신청하면 미니 이북 + 키워드 체크리스트 + ₩5,000 크레딧 + 표지 30종 갤러리 = 총 ₩49,600 가치 무료."

### 의문형 헤드라인 (Secret 18 의문형 패턴)
> **"퇴근 후 2주씩 PDF 만들기에 시달리지 않고, 한 달 ₩50만 부수익을 만들고 싶지 않으신가요?"**

### 차가운 방문자용 4종 광고 카피 (Meta/Threads 테스트용)

1. (고통 자극)
> "ChatGPT로 PDF 만들다가 매번 2주씩 걸리지 않으세요?"

2. (결과 약속)
> "퇴근 후 30분 → 크몽 ₩40,000 판매용 PDF 1권"

3. (사회적 증거)
> "박지수(32세, 마케터): 'tigerbookmaker로 월 ₩50만 부수익 만들었어요'"

4. (의문형)
> "크몽 외주 ₩300,000 한 번 vs tigerbookmaker로 평생 무제한 — 어느 게 합리적일까요?"
