# 유사 구조 — 리드 스퀴즈 퍼널 분석

- 작성일: 2026-06-01
- 카테고리: 유사 구조 (다른 업종, 같은 퍼널 유형 = 책 Secret 8)
- 분석 대상: HubSpot, Calendly, Notion (해외 SaaS)

---

## 1. 퍼널 정의 (책 Secret 8)

리드 스퀴즈 퍼널 = **무료 가치 → 이메일 수집 → 후속 시퀀스로 결제 유도**.
- 진입 장벽: 0 (카드 없음)
- 평균 등록률: **30%** (book 표준)
- 결제는 후속 5–7일 이메일 시퀀스에서 발생

## 2. 사례 1 — HubSpot (B2B 마케팅 SaaS)

### 후크
- "마케팅 전략 무료 진단" / "한국 기업 마케팅 벤치마크 리포트"

### 미끼 (Lead Magnet)
- PDF 리포트 (50–100페이지, 전문가 작성)
- 무료 진단 결과 (사이트 분석 → 점수 + 개선책)
- 무료 강의 (60분 웨비나)

### 결제 유도
- 가입 후 7일 시퀀스 (소프트오페라 Secret 7)
- 영업팀이 14일 후 콜드콜 (책 Secret 17 신청서 퍼널과 결합)

### 학습 포인트
- ✅ 미끼 자체의 품질이 신뢰의 핵심 (50페이지 PDF = 한 권 가치)
- ✅ 가입 후 즉시 가치 제공 ("3분 안에 발송")
- ❌ B2B 가격 모델 (₩300k+/월) — B2C tigerbookmaker에 직접 적용 불가

## 3. 사례 2 — Calendly (스케줄링 SaaS)

### 후크
- "일정 조율, 1초 만에"
- "Free forever for individuals"

### 미끼
- **제품 자체가 미끼** (무료 영구 사용)
- 사용해보면 가치 즉시 체감 → 자연 업셀

### 결제 유도
- 사용량 한도 (월 1개 미팅 무료 → 무제한 ₩X/월)
- 팀 기능 잠금 해제 시 결제

### 학습 포인트
- ✅ **Product-led growth** = 제품 자체가 마케팅. tigerbookmaker도 베타 ₩5,000 크레딧이 사실상 PLG.
- ✅ 사용량 한도 = 자연 업셀 트리거
- 💡 tigerbookmaker 적용: "무료로 1권 만들어 보고, 만족 시 충전"

## 4. 사례 3 — Notion (생산성 SaaS, 한국에서도 강력)

### 후크
- "All-in-one workspace"
- "Free for personal use"

### 미끼
- 무료 사용 + 템플릿 갤러리 (수천 개 무료)
- AI 기능 무료 체험 (월 20회)

### 결제 유도
- AI 무료 체험 종료 → 구독 유도
- 팀 협업 잠금 해제

### 한국 시장 특이점
- 노션은 한국에서 자체 콘텐츠 (블로그·유튜브·Threads) 강력
- 한국 대표 노션 인플루언서들이 자체 콘텐츠로 트래픽 + 노션이 후크
- 결제는 광고가 아니라 콘텐츠 → 노션 가입 → 자연 업셀

### 학습 포인트
- ✅ **한국 시장은 콘텐츠 마케팅이 광고보다 강함** — tigerbookmaker도 Threads 자체 채널 우선
- ✅ AI 기능 무료 체험 한도 = 자연 결제 유도
- 💡 tigerbookmaker 적용: "베타 ₩5,000 = 1권 무료 체험 → 자연 충전"

## 5. tigerbookmaker용 리드 스퀴즈 1번 퍼널 설계

### 후크 (차가운 방문자)
> "퇴근 후 30분, 첫 PDF 자료가 나옵니다 — 무료 미니 이북 + 크몽 키워드 체크리스트"

### 미끼 옵션 (3개)
1. **미니 이북 1편 (10페이지)** — 사용자가 주제 1줄 입력하면 즉시 PDF 발송 (실제 제품 체험 = PLG)
2. **크몽 베스트셀러 키워드 체크리스트 PDF** — 즉시 다운로드, 시장 정보 미끼
3. **5일 이메일 강좌 "30분 이북 만들기"** — 시퀀스 자체가 미끼

### 추천: **1번 (미니 이북)** + 후속으로 2, 3 합산
- 이유: 제품 가치를 즉시 체감 (Calendly·Notion PLG 모델 적용)
- v3 자산 활용 가능: 기존 `app/examples` + `lib/example-forks.ts` 인프라

### 결제 유도 시퀀스 (책 Secret 7 소프트오페라 5일)
- 1일: 무대 설정 — "AI 이북, 진짜 30분에 되는가?" + 미니 이북 발송
- 2일: 긴장 — "직장인이 매일 부수익 만드는 게 가능한가? 3가지 흔한 실수"
- 3일: 전환점 — "이렇게 하면 됩니다 — 30분 이북 만들기 라이브 예시 (영상)"
- 4일: 이득 강조 — "크몽 셀러 박OO의 한 달 ₩50만원 후기"
- 5일: 행동 — "베타 ₩0 = 라이트 1권 무료. 오늘 시작하면 ₩5,000 크레딧 +₩X 보너스"

### 측정 지표 (책 Secret 28)
- 등록률: 방문자 대비 이메일 입력 = 목표 30%
- 결제율: 등록자 대비 5일 시퀀스 후 결제 = 목표 5–10%
- ACV: 첫 결제 + OTO + 30일 LTV
- CPA: 광고비 / 결제자 수
