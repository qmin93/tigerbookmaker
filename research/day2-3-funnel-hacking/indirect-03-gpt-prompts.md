- 가격대: ₩1,900–₩29,000

---

## 1. 대상 개요

- 회사/제품: GPT/Claude 프롬프트 묶음 판매 셀러 군
- ICP 시각: tigerbookmaker가 약속하는 "AI로 결과물 자동 생성"을 사용자에게 "프롬프트만 줄게, 직접 돌려"로 약속
- 메인 후크 (대표 셀러): "ChatGPT로 한 달 ₩300만 — 검증된 프롬프트 100개"

## 2. 광고 → 랜딩 진입 경로

- 광고 본 채널: Threads/X 콘텐츠, 일부 Meta 광고
- 카피 후크: "AI로 ₩X 벌기 — 프롬프트 무료 5개" (리드 마그넷)
- 랜딩 1초 인상: 결과물 스크린샷 (생성된 이북 표지·블로그 글 등)

## 3. 후크 (Hook, Secret 18)

- 메인 헤드라인: "ChatGPT 프롬프트로 한 달 ₩300만"
- 서브헤드: "10년차 마케터가 검증한 프롬프트 100개 + 활용법"
- 시각 요소: 결과물 스크린샷 모자이크
- 방문자 온도: 따뜻한 (AI 도구 알지만 활용 모름)

## 4. 스토리 (Story, Secret 20)

- 스타: 셀러 본인 (마케터·작가·디자이너)
- 사회적 증거:
  - "5,000+ 다운로드"
  - 사용자 후기 (캡처)
  - 셀러 SNS 팔로워
- 잘못된 믿음 깨기: "프롬프트는 직접 만들어야 한다" → "검증된 거 가져다 써라"

## 5. 제안 (Offer, Secret 2)

- 메인 상품: 프롬프트 100개 묶음 + 활용 영상 + 평생 업데이트
- 가치 스택:
  - 프롬프트 100개
  - 카테고리별 분류 (글쓰기·SEO·마케팅·이미지)
  - 영상 가이드
  - 업데이트 평생
- 가격 앵커: 정가 ₩49,000 → 할인 ₩9,900
- 보장: 7일 환불
- 긴급성/희소성: "오늘만 50% 할인"

## 6. 결제 페이지

- 페이히어/Gumroad/노션 단일 결제
- 신뢰 요소: 셀러 본인 SNS 인증

## 7. 업셀 / OTO (Secret 21)

- "+₩X에 프롬프트 200개 풀팩"
- "+₩X에 1:1 30분 컨설팅"

## 8. 감사 페이지

- PDF/노션 즉시 발송 + "다음주 새 프롬프트 배달" 안내

## 9. 후속 이메일 (Secret 7)

- 주간 새 프롬프트 1개 발송 (사인필드 + 가치 누적)
- 1개월 후 업셀 제안

## 10. 학습 포인트

### ✅ tigerbookmaker가 베낄 만한 구조 (3개)

1. **결과물 스크린샷 hero** — 프롬프트 셀러는 "이걸로 만든 결과물" 보여줌. tigerbookmaker도 메인 페이지에 "생성된 이북 페이지 + 표지" 모자이크 더 두드러지게.
2. **카테고리 분류** — 100개를 글쓰기/SEO/마케팅 등으로 나눔. tigerbookmaker도 책 유형 (자기계발/실용/소설/회사매뉴얼) 분류로 ICP별 진입 분리.
3. **주간 새 프롬프트 = 가치 누적 이메일** — 책 Secret 7 사인필드 정공법. tigerbookmaker는 "주간 새 책 주제 추천" 이메일로 변형 가능.

### ❌ tigerbookmaker가 피해야 할 부분 (2개)

1. **단순 정보 묶음** — 프롬프트 판매는 "DIY" 부담을 사용자에게 떠넘김. tigerbookmaker는 **"완성품"** 강조로 차별화 (책 Secret 14 "어깨너머 보여주기"와 다른 방향).
2. **₩9,900 단일 결제** — 재구매 모티베이션 약함. tigerbookmaker 충전식 BM이 LTV 높음.

### 💡 ICP 비교

| | tigerbookmaker | GPT 프롬프트 판매 |
|---|---|---|
| 사용자 노력 | 주제 1줄 | 프롬프트 복붙 + 편집 + 정리 |
| 결과물 | 완성 PDF/EPUB | 텍스트 덩어리 |
| 재사용성 | 무제한 | 무제한 (프롬프트만) |
| 단일 결제 | 권당 차감 | 단일 ₩9.9k |
