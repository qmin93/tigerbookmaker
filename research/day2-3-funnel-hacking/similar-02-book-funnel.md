## 1. 퍼널 정의 (책 Secret 11)

책 퍼널 = **무료 책 + 배송비/처리비만 결제 → 카드 정보 확보 → 즉시 OTO**.
- 진입 장벽: ₩2,000–₩5,000 (배송비 수준)
- 핵심: 카드 정보 입력 = 가장 큰 심리 장벽 돌파
- 비교 데이터 (책 Secret 11): 197달러 직판 = 전환 1%. 같은 상품 책 퍼널 = 무료 등록 8% → 25% OTO 변환. 결과 매출 2배, 고객 8배.

## 2. 사례 1 — Russell Brunson DotCom Secrets (정공법)

### 후크
- "Free book — just pay shipping"
- "Get my $197 marketing playbook FREE"

### 미끼
- 종이책 1권 (실물 발송) — 가치 ₩40k 상당
- 배송비 ₩9,900 결제

### 결제 직후 OTO
- OTO 1: 오디오북 ₩9.9k
- OTO 2: 워크북 PDF ₩9.9k
- OTO 3: 마스터마인드 패스 ₩99k

### 학습 포인트
- ✅ "무료" 단어가 가장 강력한 미끼
- ✅ 카드 정보 입력 = 다음 결제 저항 거의 0
- ✅ 책 자체가 가치 사다리 진입 (책 읽고 → 코칭 결제)
- ❌ 종이책 = 배송 인프라 필요 (tigerbookmaker는 디지털만)

## 4. 사례 3 — 한국 시장 "무료 + 배송비" 사례

### 한국에서의 특수성
- 디지털 상품에 "배송비" 명목은 어색 → "수수료" / "결제 수수료" / "환불보증금"으로 변형 필요
- 종이책 배송 사례는 가끔 있지만 대중적 X
- 한국 부수익 책 시장: 자기계발/실용서 작가들이 본인 책 무료 + 배송비 ₩4,900으로 리드 모음

### 사례 — 김OO 자기계발 책 작가
- 후크: "베스트셀러 1만권 — 오늘만 배송비 ₩4,900에 받기"
- 미끼: 종이책 1권 (실물 발송)
- OTO: 강의 ₩99k, 1:1 코칭 ₩299k

### 한국 시장 신호
- ✅ 종이책 자체에 신뢰감 (디지털보다 가치 인식 ↑)
- ❌ tigerbookmaker는 디지털만 → "PDF 즉시 다운로드 + 처리비 ₩X" 구조 실험 필요

## 5. tigerbookmaker용 책 퍼널 변형 설계

### 시도 가능한 옵션 (Day 6에 1개 선택)

#### 옵션 A: 디지털 책 퍼널 (₩1,900 처리비)
- 후크: "AI가 만든 베스트셀러 견본 30종 — 처리비 ₩1,900"
- 미끼: PDF 책 30종 묶음 (실제 v3 examples에 30종 가까이 있음)
- OTO 1 (₩4,900): "내 주제로 1권 자동 생성 — 라이트 1회"
- OTO 2 (₩19,900): "5권 패키지 자동 생성"
- 카드 정보 확보 → 후속 자연 충전

#### 옵션 B: 무료 + 카드 정보 (책 Secret 8 변형)
- 후크: "AI 이북 30종 무료 — 카드 정보 받지 않음"
- 미끼: 동일 PDF 묶음 + 이메일만
- 카드 정보 미확보 = 책 퍼널 본질 약화. 그냥 리드 스퀴즈 (Secret 8).

#### 옵션 C: 베타 무료 + ₩5,000 크레딧 자동 (현재 v3)
- 후크: "₩5,000 크레딧 자동 = 라이트 1권 무료"
- 가입 = 카드 정보 받지 않고 결제 페이지에서 받음
- 책 퍼널보다 리드 스퀴즈에 가까움

### 추천: **옵션 A (디지털 책 퍼널)**
이유:
- 카드 정보 확보 = 책 Secret 11 핵심 가치
- 처리비 ₩1,900 = 한국 시장 마찰 최소
- 30종 묶음 = 압도적 가치 인식 (₩X × 30 = 정가 앵커)
- v3 examples 자산 100% 활용
- 한국에 동일 패턴 시도 사례 적음 = 차별점

### 측정 지표
- 진입률: 광고 클릭 → 결제 시도 = 목표 5–10%
- 결제 완료: 결제 시도 → 카드 정보 입력 = 목표 70%
- OTO 변환: 결제 직후 OTO = 목표 20–25% (책 Secret 11 기준)
- 전체 ACV: 처리비 ₩1,900 + OTO ₩X 평균
