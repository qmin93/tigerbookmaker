- 작성일: 2026-06-01
- 카테고리: 유사 구조 (다른 업종, 같은 퍼널 유형 = 책 Secret 13)
- 분석 대상: Noom (헬스), Duolingo (언어), 한국 챌린저스 (생활습관)

## 1. 퍼널 정의 (책 Secret 13)

챌린지 퍼널 = **14–30일 짧은 챌린지에 참여 → 작은 성공 경험 → 깊은 신뢰 → 본 상품 결제**.
- 진입 장벽: 챌린지 참가비 ₩X 또는 무료
- 핵심: 매일 참여 = 광고 100번보다 강한 행동 학습
- 졸업 후 브레이크아웃 오퍼 → 본 상품 결제

## 2. 사례 1 — Noom (체중 감량 14일 챌린지)

### 후크
- "What's your goal weight?" — 설문 퍼널 (책 Secret 9)로 진입
- 결과 → "Your custom plan in 14 days"

### 챌린지 구조
- 14일 무료 체험 (실제로는 ₩X 청구 — 환불 가능 형태)
- 매일 짧은 과제 + 코칭 메시지
- 사용자 본인 데이터 추적 → 시각화

### 졸업 시 브레이크아웃
- "14일 결과 = ₩X kg 감량. 다음 단계 = 월 ₩X 구독"
- 무료 체험 종료 자동 결제

### 학습 포인트
- ✅ 설문 퍼널(Secret 9) → 챌린지 진입 = 책 Secret 9 + 13 결합 정공법
- ✅ 매일 가벼운 과제 = 책 Secret 13의 "작은 성공 누적"
- ❌ 자동 결제 (다크 패턴) — 한국 시장에서는 신뢰 손상 risk

## 3. 사례 2 — Duolingo (언어 학습)

### 후크
- "5분만에 배우는 OO어"
- "100% 무료"

### 챌린지 구조
- 매일 5분 학습 = 본질적 챌린지
- 연속 학습 일수 (Streak) — 게이미피케이션
- 친구와 경쟁

### 결제 유도
- 광고 노출 → Super (월구독) 업셀
- 가족 플랜 = LTV ↑

### 학습 포인트
- ✅ **매일 5분 = tigerbookmaker의 "퇴근 후 30분"과 비슷한 약속**
- ✅ 연속 사용 = 책 Secret 27 (한 번에 하나만) 정공법
- 💡 tigerbookmaker 적용: "7일간 매일 미니 이북 1편 — 7권 완성 챌린지"

## 4. 사례 3 — 챌린저스 (한국 생활습관 챌린지 앱)

### 후크
- "보증금 걸고 챌린지 — 성공하면 돌려받기"
- "OO일 챌린지 — 성공률 80%"

### 챌린지 구조
- 7–30일 챌린지
- 참가비 ₩10,000 (보증금) — 성공 시 환급
- 매일 인증 (사진/체크)

### 졸업 시
- 다른 챌린지 추천 + 상위 챌린지 결제

### 학습 포인트
- ✅ **한국 시장 검증된 챌린지 모델** — 보증금 환급 = 신뢰 + 책임감
- ✅ 매일 인증 = 책 Secret 13의 "변화 모습 시각화"
- 💡 tigerbookmaker 적용: "14일 14권 챌린지 — 보증금 ₩X. 인증 시 환급 + 명예의 전당"

## 5. tigerbookmaker용 챌린지 퍼널 설계

### 옵션 A: 7일 7권 챌린지 (가벼움)
- 참가비: 무료 + 베타 크레딧 ₩5,000 자동
- 매일: 미니 이북 1편 자동 생성 + Threads 인증
- 졸업 시: "이제 풀버전 책 만들기 — ₩4k부터" 자연 업셀
- 적합: 진입 장벽 최소, 자체 채널 빠르게 키움

### 옵션 B: 14일 14권 챌린지 (한국 챌린저스 모델)
- 참가비: ₩29,000 (보증금, 완주 시 ₩29k 크레딧 환급)
- 매일: 1권 자동 생성 + 표지 + 인증
- 졸업 시: "30권 마스터 코스 ₩99k" 브레이크아웃 오퍼
- 적합: ACV ↑, 결제 행동 즉시 발생

### 옵션 C: 30일 인플루언서 챌린지 (포지셔닝)
- 참가비: ₩99,000 (코호트)
- 30일 = 30권 + SEO + 크몽 등록 가이드 + 1:1 피드백
- 졸업 시: 출판 컨설팅 ₩2M+ 신청서 퍼널
- 적합: 가치 사다리 층 3→4 진입

### 추천 우선순위
1. **옵션 A** (7일 챌린지) — 1번 퍼널 후보. 진입 장벽 최소, 데이터 빠르게 수집.
2. **옵션 B** (14일 챌린지) — 1번 퍼널 안정화 후 추가. ACV 검증된 후 실험.
3. **옵션 C** (30일) — Month 3+ 가치 사다리 층 3→4 연결 (Week 1 범위 외)

### v3 챌린지 코드 재사용도
- `app/challenges/page.tsx` 존재 → 옵션 A/B 구현 시 70% 코드 재사용

### 측정 지표 (책 Secret 28)
- 참가율: 랜딩 방문 → 챌린지 참가 = 목표 10–20%
- 완주율: 참가 → 7일 완주 = 목표 30–50%
- 브레이크아웃 변환: 완주자 중 본 상품 결제 = 목표 30%+ (책 Secret 13 기준)
