## 🌍 글로벌 — 5개 검증 직접 경쟁사

### 1. AI eBook Suite ⭐ 최우선 해킹 후보

- **URL**: https://aiebooksuite.com/ko/ (한국어 로컬라이즈 있음)
- **가격**: $15/mo (창립자 가격) → $39/mo, 무제한 책, BYOK (OpenRouter/OpenAI/Straico)
- **타겟**: 작가·교육자·기업가
- **핵심 포지셔닝**: "**50권/일 = $4,785/월 패시브 수익**" (Amazon KDP 70% 로열티 기반)
- **광고 카피**: "30분 만에 첫 전자책 생성", "지금 무료 시작"
- **해킹 가치**: ⭐⭐⭐ — tigerbookmaker의 "직장인 부수익러" 포지셔닝과 거의 1:1 매칭. 한국어 UI 까지 깔려 있음 → 후크·카피 그대로 모델링 가능.
- **위치**: 스페인 카나리아 제도 (BertoProduction)

### 2. Inkfluence AI ⭐ 두 번째 해킹 후보

- **URL**: https://www.inkfluenceai.com/ai-ebook-generator
- **가격**:
  - Free: 5챕터 시작 + 월 5챕터, PDF 출력, **카드 없음** (리드 마그넷 = 진입 자체)
  - Creator $9.99/mo: 35챕터/월, EPUB/DOCX, 15 오디오북 챕터
  - Premium $19.99/mo: 무제한 챕터, 브랜드 제거
  - 연간 $89/$179
- **타겟**: 코치/컨설턴트, 콘텐츠 크리에이터, 솔로프리너, 코스 크리에이터, **KDP 셀프퍼블리셔**
- **활성 사용자**: 1만 명 근접 (Indie Hackers 창립자 인용)
- **해킹 가치**: ⭐⭐⭐ — ICP-3 (1인 코치) 정확 매칭 + 리드 마그넷 (무료 5챕터) = 책 secret 8 리드 스퀴즈 정석.

### 3. Automateed ⭐ 세 번째 해킹 후보 (BM 변형)

- **URL**: https://www.automateed.com/ai-automateed-pricing
- **가격**:
  - Standard $25/mo (8 ebooks/mo)
  - Pro $50/mo (30 ebooks/mo, "Most Popular")
  - **Lifetime $149+** (Entry = 4 ebooks/mo)
- **무료 미끼**: **5,000단어 무료 체험, 카드 없음**
- **타겟**: KDP 셀프퍼블리셔, 기업가
- **광고 포지셔닝**: "85% 로열티 vs Amazon 35-70%", "No exclusivity", "Monthly auto-payouts vs Amazon's 60-day wait"
- **해킹 가치**: ⭐⭐ — 라이프타임 BM + 명확한 리드 마그넷 = tigerbookmaker가 차용 가능한 패턴

### 4. NovelCrafter (인접 경쟁사)

- **URL**: https://www.novelcrafter.com/pricing
- **가격**: Scribe $4 / Hobbyist $8 (Most popular) / Artisan $14 / Specialist $20
- **BYOK**: Hobbyist($8)부터, $4 Scribe는 BYOK 없음. 실제 비용 $14–$70/월 (Reddit 사용자 후기)
- **타겟**: 진지한 소설 작가 ("every story deserves to be told")
- **해킹 가치**: ⭐ — 타겟 다름 (ICP 일치도 낮음). 가격 구조만 참고.

### 5. Sudowrite (인접 경쟁사)

- **URL**: https://sudowrite.com/pricing
- **가격**: Pro / Max $44/mo
- **타겟**: 소설·시나리오 작가, 'Muse model' (소설 특화)
- **해킹 가치**: ⭐ — KDP 볼륨 퍼블리셔나 한국 부수익러 타겟 X.

### 6. Squibler (인접 경쟁사)

- **URL**: https://www.squibler.io/pricing/
- **가격**: Free (1k 크레딧/월) / Plus $29.99/mo (10k 크레딧, "Most Popular") / Pro $89.99/mo (무제한)
- **해킹 가치**: ⭐ — 크레딧 BM 참고만.
