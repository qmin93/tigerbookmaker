## 1. 대상 개요

- 회사/제품: **크몽** — 한국 1위 프리랜서 마켓플레이스. 이북 카테고리에 직접 콘텐츠 제작 외주 + 완성된 PDF 자료 판매가 공존.
- ICP 시각: tigerbookmaker가 자동화하려는 행동(이북 만들기)을 사람(외주 작가)에게 시키는 대안.
- 가격대: 외주는 ₩50k–₩500k, 완성 PDF는 ₩5k–₩50k
- 메인 후크 (크몽 자체): "전문가가 5분 만에 다 알려드려요" / "프리랜서 마켓 1위"

## 2. 광고 → 랜딩 진입 경로

- 광고 본 채널: TVCF, 네이버 검색 광고 ("크몽"·"외주" 키워드), Meta 리타겟팅
- 광고 카피: "전문가 N만 명" / "지금 카테고리 검색"
- 랜딩 1초 인상: 거대 검색바 + 카테고리 그리드 = 마켓플레이스 정공법

## 3. 후크 (Hook, Secret 18)

- 크몽 카테고리별 후크 다름. 이북 자료 카테고리 후크: "검증된 자료 → 즉시 다운로드"
- 방문자 온도: 뜨거운 (이미 크몽 신뢰)

## 4. 스토리 (Story, Secret 20)

- 스타: 개별 셀러 (각자 프로필·후기·판매 수)
- 사회적 증거 (매우 강함):
  - 후기 점수 (5.0/4.9)
  - 판매 수 ("1,000+ 판매")
  - 셀러 등급 (브론즈/실버/골드/프라임)
- 잘못된 믿음 깨기: "직접 만드는 것보다 사는 게 빠르다"

## 5. 제안 (Offer, Secret 2)

- 메인 상품: 완성 PDF 자료 1건 (즉시 다운로드)
- 가격 앵커: 정가/할인가 표시
- 보장: ❌ (크몽 환불 정책에 따름)
- 긴급성/희소성: ❌ 일반적으로 없음

## 6. 결제 페이지

- 1-페이지 통합 결제 (장바구니 → 결제)
- 결제 수단: 카카오페이/네이버페이/카드/계좌이체 (한국 종합)
- 신뢰 요소: 크몽 보증, 후기

## 7. 업셀 / OTO (Secret 21)

- 카테고리 추천 (관련 상품), 묶음 추천
- "이 자료와 함께 본 자료" (책 Secret 12 오퍼월 패턴)

## 8. 감사 페이지

- 다운로드 링크 + "다른 자료 보기" + 후기 요청

## 9. 후속 이메일 (Secret 7)

- 크몽 자동 마케팅 이메일 (카테고리별 추천)
- 셀러별 직접 이메일 없음 (셀러는 크몽 통해서만 연락)

## 10. 학습 포인트

### ✅ tigerbookmaker가 베낄 만한 구조 (3개)

1. **후기 시스템** — 별점 + 판매 수 + 등급. tigerbookmaker도 v3에 작가 프로필·후기 있음. 더 두드러지게.
2. **카테고리별 베스트셀러** — "이주의 1위" 같은 사회적 증거. tigerbookmaker는 책별 카테고리 베스트 라벨 추가 가능.
3. **즉시 다운로드 UX** — 결제 → 1클릭 다운로드. tigerbookmaker의 PDF/EPUB/DOCX 다운로드 흐름이 이미 잘 되어 있음.

### ❌ tigerbookmaker가 피해야 할 부분 (2개)

1. **카테고리 그리드 산만함** — 크몽은 한 페이지에 너무 많은 옵션. tigerbookmaker는 책 Secret 0 (퍼널) 원칙 따라 단일 동선 유지.
2. **셀러-구매자 분리 BM** — 크몽은 셀러가 따로 노력해야 함. tigerbookmaker는 셀러=구매자 통합 모델 유지.
