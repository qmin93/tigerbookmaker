# 노션 템플릿 판매자 — 간접 경쟁사 퍼널 해킹 노트

- 작성일: 2026-06-01
- 카테고리: 간접 (같은 ICP 부수익러, 다른 제품 카테고리 = 노션 템플릿)
- 대표 채널: 노션 한국 마켓플레이스, 셀러 개인 사이트, 페이히어/카드웨이브, Gumroad
- 가격대: ₩4,900–₩49,000

---

## 1. 대상 개요

- 회사/제품: **노션 템플릿 판매자 군** (개인 셀러). 대표 한국 셀러 예: Sequel, Notion Korea 추천 작가들
- ICP 시각: tigerbookmaker가 노리는 부수익 ICP와 거의 동일. 다만 결과물이 "노션 페이지/템플릿"이지 "PDF/이북"이 아님.
- 카테고리: 간접
- 가격대: 단일 템플릿 ₩4,900–₩19,000, 번들 ₩29,000–₩49,000

## 2. 광고 → 랜딩 진입 경로

- 광고 본 채널: Threads/X 콘텐츠 마케팅 (광고 X, 콘텐츠 100%) — 책 Secret 8의 "콘텐츠 → 리드 스퀴즈" 정공법
- 카피 후크: "퇴근 후 부업 노션 템플릿" / "1만 다운로드 달성"
- 랜딩 1초 인상: 노션 페이지 스크린샷 + 즉시 결제 버튼

## 3. 후크 (Hook, Secret 18)

- 메인 헤드라인 (셀러별 다름): "직장인 부업 시작 — 완성된 노션 시스템"
- 서브헤드: "10분 세팅으로 한 달 ₩50만원"
- 시각 요소: 노션 페이지 스크린샷 (시각 즉시 어필)
- 방문자 온도: 따뜻한 (노션 이미 알고 부업 찾는 사람)

## 4. 스토리 (Story, Secret 20)

- 스타: **셀러 본인 페르소나 강함** (책 Secret 4 매력적인 캐릭터 정공법)
  - 예: "직장인 5년차, 노션으로 월 100만원 부수익 만든 김OO"
- 사회적 증거:
  - 다운로드 수 ("1만+")
  - SNS 팔로워 수 인용
  - 후기 스크린샷
- 잘못된 믿음 깨기: "복잡한 노션은 학습 1주" → "이 템플릿 = 10분 세팅"

## 5. 제안 (Offer, Secret 2)

- 메인 상품: 노션 템플릿 + 영상 가이드 + 평생 업데이트
- 가치 스택:
  - 노션 템플릿 (예: 부업 관리)
  - 10분 셋업 영상
  - 평생 업데이트
  - 디스코드 커뮤니티
- 가격 앵커: 정가 ₩29,000 → 할인 ₩9,900
- 보장: 7일 환불 (일부)
- 긴급성/희소성: "선착순 100명 / 다음주 가격 인상"

→ **책 Secret 2 + Secret 4 동시 구현 모범**.

## 6. 결제 페이지

- 페이히어/카드웨이브/스마트스토어 활용 (1-페이지)
- 결제 수단: 카드/카카오페이/네이버페이
- 신뢰 요소: 셀러 SNS 링크 + 후기 스크린샷

## 7. 업셀 / OTO (Secret 21)

- 결제 직후: "+₩X에 부업 전체 패키지" / "+₩X에 1:1 코칭 30분"
- 셀러에 따라 다름

## 8. 감사 페이지

- 이메일로 즉시 발송 + "다른 템플릿 추천"

## 9. 후속 이메일 (Secret 7)

- 디스코드/카톡 채널 초대
- 정기 뉴스레터 (작가 본인 글)
- 사인필드 + 소프트오페라 혼합

## 10. 학습 포인트

### ✅ tigerbookmaker가 베낄 만한 구조 (3개)

1. **셀러 페르소나 = 캐릭터** — 책 Secret 4 그대로. "직장인 5년차, 월 100만 부수익" 같은 검증된 페르소나. tigerbookmaker "김과장"으로 1:1 매핑 가능.
2. **콘텐츠 → 리드 → 결제 자연 흐름** — 광고 0원, Threads/X 콘텐츠로만 트래픽. tigerbookmaker도 Threads로 자체 채널 키우기 전략.
3. **가치 스택 (영상 가이드 + 평생 업데이트 + 커뮤니티)** — 단일 제품 + 부수 자료로 가치 부풀리기.

### ❌ tigerbookmaker가 피해야 할 부분 (2개)

1. **노션 결과물의 시각 즉시성** — 노션은 스크린샷 한 장으로 가치 어필. 이북은 표지 1장 + 챕터 목차로 어필 약함. **표지 갤러리 + 챕터 목차 미리보기**를 메인 hero에 배치 필요 (v3 코드에 이미 있음 — Phase 3 표지 갤러리).
2. **단일 셀러 = 단일 페르소나** — 노션 셀러는 본인이 평생 운영. tigerbookmaker는 SaaS이니 "회사 페르소나" 만들기 더 어려움. **김과장 캐릭터 강화 필수**.

### 💡 ACV/CPA 추정

- 추정 ACV (단일 결제): ₩9,900 (단일 템플릿) — 재구매 적음
- 추정 CPA: ₩0 (콘텐츠 마케팅) → 광고 도입 시 ₩5,000–₩15,000
- 가설: 광고 의존 없음 = 콘텐츠 자산 핵심. tigerbookmaker도 자체 콘텐츠 채널 (블로그/Threads/유튜브) 시동 추천.
