| 유입 채널 가설 | Threads 글쓰기 콘텐츠, Maily 추천, 뉴스레터 상호 소개, 트위터 작가 커뮤니티 |
| 미끼 가설 | "블로그 글 → 미니 이북 1편 자동 변환" 데모 + 작가 톤 유지 가이드 |

## ICP-3: 1인 코치 / 강사 (오프라인 강의 + 온라인 콘텐츠)

| 항목 | 가설 |
|---|---|
| 이름 (상상) | 이정훈, 38세 남성 |
| 직업/상황 | 영어 회화 1:1 코치, 인스타 팔로워 6,500명, 오프라인 그룹 코칭 + 인프런 강의 1개 운영 |
| 어디 모이나 | 인프런 강사 카페, Class101 셀러 그룹, 페북 "1인 지식창업" 그룹, 인스타 강사 DM 네트워크 |
| 외부 목표 | 자기 이름의 학습서 1권 출판 (포지셔닝 강화), 수강생에게 무료 가이드북 제공, 강의 객단가 ₩X → ₩2X 인상 |
| 내부 목표 | "전문가 권위" 강화, 강의 외 패시브 수익, 책 = 명함 |
| 현재 어떻게 | 강의 자료를 PPT로 작성 → 책으로 만들고 싶은데 시간 없음 → 외주 작가 견적 ₩300–500만원 보고 포기 |
| 가장 큰 페인 | (1) 시간 부족 (코칭이 본업), (2) "강의 자료 → 책" 변환이 큰 작업, (3) 외주 비용 부담, (4) 디자인·인쇄까지 한 번에 안 됨 |
| 지불 의사 가설 | ₩59k 단권 (강의 자료 import 포함) / ₩199k 월구독 / ₩990k 출판 컨설팅 패키지 (가치 사다리 층 4 후보) |
| 유입 채널 가설 | 인스타 1인 창업 콘텐츠, 인프런 강사 커뮤니티, 페북 그룹, 유튜브 "1인 강사 책 출판" 검색 |
| 미끼 가설 | "강의 PPT 1개 → 미니 이북 1편 자동 변환" 데모 + 책=명함 가이드 |
