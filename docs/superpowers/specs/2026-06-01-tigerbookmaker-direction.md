# 2026-06-01 tigerbookmaker 방향 재검토 — Week 1 퍼널 진단

> 본 문서는 *마케팅 설계자* (러셀 브런슨) 독후감 (2026-06-01) 기반으로 작성된 방향 재검토 spec.

## 1. 배경

v3 Phase 1–4 + 이미지 시스템 + 외부 연동까지 모두 머지 완료. 베타 런칭 직전 상태로 2026-05-13에 작업 중단, 18일간 정지. 중단 사유는 시장/제품 문제가 아니라 다른 업무(managerkim 온보딩) 우선순위 충돌.

현재 풀타임 재투입 가능. 단순 베타 런칭이 아니라 **제품·시장·고객·BM 전체를 재검토** 하기로 결정.

## 2. 자기진단 (독후감 secret 0 인용)

> "예를 들어, 제가 작업했던 Tigerbookmaker같은 웹사이트 경우, 선택지 혹은 기능이 너무 잡다했습니다. 고객이 처음 사이트에 들어온 순간부터 결제까지, 단계별로 길을 깔아두고 한 번에 하나씩만 결정하게 만드는 구조를 만들었어야 제대로된 퍼널인데 그게 미흡했었습니다."

**핵심 문제 = 퍼널 부재.** v3 스코프가 작아서가 아니라, 흩어진 기능을 하나의 명확한 동선으로 묶는 구조가 빠져 있다. 따라서 Week 1의 목적은 **시장 검증 + 퍼널 v1 설계**.

## 3. 성공 정의 (사용자 합의)

1. **수익**: 월 100만원+ 매출
2. **유저베이스**: 자체 채널/리텐션 — 광고 없이도 자라는 사용자 풀

지속 가능한 SaaS. 책의 conclusion 9단계와 정렬: 첫 퍼널이 ACV > CPA가 될 때까지 반복 → 100만 달러 → 다음 퍼널 포개기.

## 4. 비교한 옵션

| 옵션 | 기간 | 비용 | 적합도 |
|---|---|---|---|
| A. 시장 진단 + 퍼널 v1 설계 후 GO/NO-GO | 1주 | 낮음 | ⭐⭐⭐ |
| B. 그대로 베타 런칭 | 1–2주 | 광고 ₩30–50만 | ⭐⭐ (자기진단상 퍼널 부재 → 광고비 새는 구조) |
| C. MVP 압축 + 재설계 | 2–3주 | 시간 큼 | ⭐ |

**선택: A.** 이유:
- 책 secret 28 "첫 퍼널은 매출이 아니라 데이터를 얻기 위한 것" — 그래도 퍼널 구조부터 설계해야 데이터가 해석됨. 지금 베타 런칭하면 ACV/CPA 데이터를 어디서 새고 있는지 진단 불가.
- 책 secret 27 "한 번에 다 만들지 말 것" — 현재 v3는 "다 만들어 둔" 상태. 1번 퍼널 하나만 골라 집중해야 함.
- 책 secret 5 "퍼널 해킹" — 직접 경쟁사 10개를 모델링하는 작업이 1주 안에 가능.

## 7. GO / PIVOT / NO-GO 트리거

책 secret 28 (ACV > CPA) 기반.

**GO (다음 주부터 1번 퍼널 풀빌드 + 광고 테스트)**
- 인터뷰 5명 중 3명 이상이 외부+내부 목표를 명확히 표현 + 지불의사 표현
- 퍼널 해킹에서 ACV/CPA 추정이 합리적 (광고비 ₩X → 1명 확보 가능 가설 성립)
- 리드 스퀴즈 랜딩 3일 안에 등록 30%+ (book 표준)
- 광고 정책 막힘 없음

**PIVOT (스코프·ICP·BM 변경 후 진행)**
- 인터뷰에서 진짜 페인포인트가 v3 기능과 다름 → ICP/제안 재정의
- 광고 정책 막힘 → SEO/제휴/서밋 퍼널(Secret 10)로 채널 전략 전환
- 가치 사다리에서 무료/저가 진입점이 v3에 없음 → 새 진입점 설계

**NO-GO (보류 또는 중단)**
- 인터뷰 결과 ICP가 명확히 존재하지 않음
- 직접 경쟁사가 무료 또는 가격경쟁 불가 수준
- 리드 스퀴즈 랜딩 등록 < 5%
